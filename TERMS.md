## 1. Preamble and Description of Software

AnyPS5 Studio ("the Software", "the Application") is an independent, open-source PlayStation 5 executable launcher, runtime manager, and binary relinking orchestration utility. The Software is developed and provided solely for personal research, educational study, computer science analysis, software interoperability, and digital preservation.

AnyPS5 Studio operates by coordinating clean-room reimplementations of system libraries and native binary relinking to execute compatible PlayStation 5 binaries on host operating systems (Windows and Linux). The Software is neither an emulator nor a circumvention tool.
